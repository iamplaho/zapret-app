# zapret-app

Приложение для Windows, которое включает обход блокировок Discord и YouTube одним кликом.
Без консолей и ручного редактирования `.bat`-файлов.

Основано на [flowseal/zapret-discord-youtube](https://github.com/flowseal/zapret-discord-youtube) (MIT).
Авторы и лицензии — в NOTICE.md.

## Возможности

- Кнопка «Включить / Выключить» и статус обхода.
- Выбор стратегии из 22 вариантов оригинального репозитория.
- Игровой фильтр — ускорение игровых серверов.
- Автообновление списков из официального репозитория (отключается в настройках).
- Ручная проверка обновлений.
- Значок в трее: открыть окно, включить или выключить обход, выход.
- Сворачивание в трей при закрытии окна (можно отключить).
- Автозапуск вместе с Windows: приложение стартует в трее и сразу включает обход.
- Защита от двойного запуска.
- Журнал событий.
- Установщик с удалением: при установке и удалении обход останавливается, задача автозапуска удаляется.

## Установка для пользователей

1. Скачайте `zapret-app-setup-<версия>.exe` со страницы Releases.
2. Запустите установщик. Он попросит права администратора.
3. Откройте zapret-app, выберите стратегию и нажмите «Включить».
4. Если Discord или YouTube не открываются, попробуйте другую стратегию.

Windows SmartScreen может показать предупреждение «Неизвестный издатель», потому что установщик
не подписан сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

Есть и портативная версия: `zapret-app-portable-<версия>.zip`. Её можно распаковать в любую папку и запустить `zapret-app.exe`.

Настройки, списки и журналы хранятся в `%APPDATA%\zapret-app`. При удалении эта папка остаётся,
её можно удалить вручную.

## Сборка

### Через GitHub Actions (ничего не нужно устанавливать)

1. Создайте репозиторий и загрузите в него содержимое этой папки.
2. Каждый push в `main` запускает сборку. Файлы появляются в **Actions** → последний запуск → **Artifacts**.
3. Чтобы выпустить версию: `git tag v0.2.0 && git push --tags`. Установщик и портативный архив
   автоматически прикрепятся к **Releases**. Номер версии берётся из тега.

### Локально на Windows

Нужны Python 3.10+ (с PATH) и, для установщика, [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```bat
build.bat
```

Результаты: `dist\zapret-app\zapret-app.exe` (портативная версия) и `installer-output\zapret-app-setup-*.exe` (установщик).

### Разработка

```bash
pip install -r requirements.txt
python main.py                          # только на Windows и от имени администратора
python -m unittest discover tests       # тесты ядра работают на любой ОС
```

### Пересобрать стратегии из оригинала

```bash
python tools/convert_strategies.py <путь_к_zapret-discord-youtube> runtime/strategies.json
```

## Как работает автообновление

При запуске (если включено) приложение скачивает из репозитория `list-general.txt`, `list-google.txt`,
`list-exclude.txt`, `ipset-exclude.txt` и `ipset-all.txt`. Обновляются только изменившиеся файлы.
Если обход уже работает, он перезапускается с новыми списками.

Не обновляются автоматически:
- `winws.exe` и драйвер WinDivert. Их обновление требует проверенного релиза.
- Файлы `*-user.txt`. Туда можно добавлять свои домены и IP, они сохраняются.

## Частые вопросы

**Обход не запускается.** Запустите приложение от имени администратора. Посмотрите `winws.log` в `%APPDATA%\zapret-app`.

**Антивирус ругается.** Обход использует драйвер перехвата пакетов, поэтому такие срабатывания возможны.
Добавьте папку приложения в исключения.

**Конфликт с VPN или другими обходами.** Выключите их на время проверки.

**Не работает у моего провайдера.** Попробуйте другие стратегии. Результат зависит от оператора.

**Обход продолжает работать после закрытия приложения.** Это сделано намеренно. Выключить его можно в окне
или в меню трея. При удалении приложения обход останавливается автоматически.

**Как выключить автозапуск.** Снимите переключатель в настройках или удалите задачу `zapret-app-autostart`
в планировщике заданий.
