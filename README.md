# zapret-app

Программа для Windows, которая обходит блокировки Discord и YouTube. Всё управляется
мышкой: никаких консолей и ручного редактирования файлов.

Основана на [flowseal/zapret-discord-youtube](https://github.com/flowseal/zapret-discord-youtube)
(лицензия MIT). Авторы и лицензии указаны в файле NOTICE.md.

## Установка

Программа распространяется только через установщик.

1. Откройте страницу **[Releases](https://github.com/iamplaho/zapret-app/releases)** и скачайте последнюю версию.
2. Запустите установщик и подтвердите запрос прав администратора.
3. Windows SmartScreen может написать «Неизвестный издатель», потому что программа не подписана
   сертификатом. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
4. Нажмите на круг на главной вкладке.

Установщик удаляет программу через «Программы и компоненты». При удалении обход останавливается,
служба и драйвер WinDivert удаляются.

## Как пользоваться

**Главная.** Круг включает и выключает обход. Серый — выключено, пульсирует — запуск,
белый — работает. Ниже выбирается стратегия. Кнопки «Проверить стратегию» и «Подобрать лучшую»
проверяют доступность Discord и YouTube. Лучшая стратегия выбирается сама.

**Настройки.**
- *Игровой фильтр* — ускоряет игровые серверы. Режимы: выключен, TCP и UDP, только TCP, только UDP.
  Порты можно изменить.
- *IPSet фильтр* — список IP-адресов. «Загруженный список» — полный список из репозитория,
  «Выключен» и «Любые IP» — как в оригинале.
- *Сворачивать в трей* и *Запускать с Windows* — поведение при закрытии и старте системы.
- *Обновлять списки* и *Обновлять программу* — автоматические обновления. Их можно выключить.
- *Открыть папку списков* — здесь лежат все списки. Свои домены добавляйте в файлы `*-user.txt`.

**Сервис.**
- *Установить службу* — служба Windows запускает обход при загрузке системы, даже до входа в учётную
  запись. Пока служба установлена, круг на главной управляет ею. После изменения настроек службу
  можно не переустанавливать: параметры обновляются сами.
- *Удалить службы* — удаляет службу и драйвер WinDivert.
- *Статус* — показывает состояние службы, процесса winws.exe и драйвера.
- *Диагностика системы* — проверяет BFE, системный прокси, TCP timestamps, конфликтующие службы
  (GoodbyeDPI, winws1/2 и др.), Adguard, Killer, Intel Connectivity, Check Point, SmartByte и VPN.
  Найденное выводится с пояснением. TCP timestamps программа включает автоматически.
- *Обновить список IPSet* — скачивает свежий полный список IP.
- *Обновить hosts* — добавляет в файл hosts записи Discord и YouTube, которых там нет.
  Старый файл сохраняется как `hosts.zapret-app.bak`. В оригинале этот шаг делается вручную.
- *Фейковые пакеты* — выбор файла из папки `bin`, который подменяет трафик для Discord и игр.
  Меняйте его, если стратегия не работает.

**Журнал** внизу окна показывает последние события. Кнопка **«Развернуть»** открывает журнал в отдельном окне, **«Очистить»** стирает записи.

## Обновления

Программа сама проверяет новые версии при запуске. Если найдена новая версия и включено
«Обновлять программу», она скачивает установщик, закрывается и открывает новую версию.
Если обход работал, он включится снова. Списки доменов и IP обновляются отдельно, из
официального репозитория.


## Структура проекта

```
main.py                        точка входа
zapret-app.spec                сборка PyInstaller
zapret_app/
  ui.py                        главное окно и вкладки
  logpanel.py                  нижняя панель журнала
  power_circle.py              круг включения с анимацией
  theme.py                     монохромная палитра
  engine.py                    обход: процесс winws.exe и служба Windows
  tester.py                    проверка и подбор стратегий
  diagnostics.py               диагностика системы и статус
  updater.py                   списки и режим IPSet
  fakes.py                     фейковые пакеты
  hosts.py                     обновление файла hosts
  app_updater.py               обновление самой программы
  strategies.py                стратегии и порты
  tray.py                      значок в трее
  settings.py, paths.py, system.py
runtime/
  bin/                         winws.exe, WinDivert и пакеты обхода (из оригинала)
  lists/                       стартовые списки
  strategies.json              22 стратегии из оригинала
  targets.txt                  адреса для проверки стратегий (из оригинала)
installer/zapret-app.iss       установщик Inno Setup
tests/test_core.py             тесты
.github/workflows/build.yml    сборка установщика и релизы
```

Где что хранится:
- настройки и журналы: `%APPDATA%\zapret-app`;
- списки и параметры службы: `%ProgramData%\zapret-app\lists`.

## Частые вопросы

**Обход не запускается.** Запустите программу от имени администратора. Откройте **Сервис → Диагностика системы**.

**Discord или YouTube не открываются.** Нажмите «Подобрать лучшую». Если не помогло, попробуйте
фейковые пакеты или отключите VPN и прокси.

**Антивирус ругается.** Драйвер WinDivert часто вызывает ложные срабатывания. Добавьте папку программы в исключения.

**Служба не устанавливается.** Удалите старые службы («Сервис → Удалить службы») и повторите.
Если ошибка остаётся, перезагрузите компьютер.
